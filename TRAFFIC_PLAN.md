# Traffic plan for ashayojana.com (practical, no shortcuts)

## Week 1 (one-time setup, owner does these)
1. Google Search Console: add property https://ashayojana.com, verify, submit https://ashayojana.com/sitemap.xml. Use URL Inspection > Request indexing for the 10 newest pages. Check Pages report weekly.
2. Bing Webmaster Tools: import from Search Console (free, 2 min).
3. Link GA4 with Search Console (GA4 Admin > Product links) so queries show in GA.
4. Create a WhatsApp Channel and Telegram channel "Asha Yojana". Post each new scheme link (title + 1 line + link) daily. This is the biggest early traffic source for scheme sites in India.
5. Facebook page + Instagram/YouTube Shorts: 30-45 sec "kisko milega / kaise apply karein" videos linking to the page.

## Ongoing (routine does these)
- 5 verified pages a day; refresh older pages when amounts/dates change and bump the "last checked" date only when really re-verified.
- Prefer queries people actually search: "<scheme> payment status", "<scheme> eligibility", "<scheme> apply online", "<scheme> list". Add "how to check status" / "payment not received" sections only when the steps are verified.
- Cross-link related schemes (same state, same category) inside the text.
- Do not publish thin or unverified pages; AdSense reviewers and Google's helpful-content systems look at overall site quality.

## Do not
- Do not try to hide AI use or spin text to evade detection; Google ranks on usefulness/accuracy, and scaled low-value pages are the risk. Accuracy, sources, dates and a named owner/contact are the protection.
- Do not buy backlinks or traffic.

## Later (month 2+)
- Get real backlinks: local news/blog mentions, CSC operator groups, scheme-related forums, answers on Quora/Reddit with link to the exact page only when it fully answers the question.
- Add "Sources" lines on each page after verifying.
